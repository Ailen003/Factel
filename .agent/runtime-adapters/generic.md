# Generic Runtime Adapter

Map native capabilities for root/executor identity, role selection, spawn,
activity, steering, waiting, interruption, completion capture, permission
inheritance, and exclusive writers.

Every executor receives `HARNESS_EXECUTOR_V1`, a concise scope, roots, exact
skills, constraints, expected checks, and exclusive artifacts when writing.
High-risk irreversible work also names the direct user-confirmation boundary.

When subagents are unavailable, work inline if the scope remains safe. If a
writer must be replaced, stop and confirm the prior writer before another
writer touches its exclusive artifact. Invisible intermediate activity is not a
failure; return the observed outcome.

Vendor-specific controls do not redefine scope, ownership, direct user
confirmation, or the structured conversational result. Native plans are
optional and are never required or stored by this harness. Agents never run
`git commit`.

For verification assignments, keep executor `status` separate from the
observed `verdict` (`PASS`, `FAIL`, or `not-run`) as defined by the phase-handoff
contract.
