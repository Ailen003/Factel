# Harness Documentation

These guides describe a lightweight, guide-only way to collaborate in this
repository. They are practical references, not an executable workflow or a
release gate.

- `developer-harness-guide.md`: everyday implementation, delegation, and
  verification guidance.
- `human-operator-guide.md`: what a user can expect from an agent and how to
  review a result.
- `harness-audit-report.md`: historical lessons, current limits, and the
  simplification record.
- `../.agent/`: reusable roles, skills, contracts, and implementation
  references.

Product knowledge belongs in `docs/`. The coding tool or agent chooses any
native planning that helps. Agents use patterns, may delegate clear independent
work, run proportionate checks, and never create git commits. PASS means ready
for manual user review and commit.
