> material iteration touches an existing requirement. Do not backfill untouched
> historical requirements. Update current state in place and keep the
> iteration table append-only.

| Field | Value |
|---|---|
| Status | not-started \| active \| paused \| ready-for-manual-commit |

## Current State

Summarize what is true now, the current intended outcome, remaining risks, and
the next step. A final PASS means the work is ready for the user to review and
commit manually; agents do not run `git commit`.

## Iterations

Append a row when material work starts and another when it closes. Preserve
earlier rows except to correct a factual error.

| Date | Iteration | Status | Evidence and deferred work |
|---|---|---|---|
